## cPanel-登录控制面板模板
集成短链生成、子域名托管、无限邮箱服务，以及开放 API 接口

一站式域名服务（Saas）平台，释放你的域名潜力。搭配完整的管理后台，支持用户权限控制和各项系统配置

### 短链接服务：
自定义短链接

生成自定义二维码

受密码保护的链接

过期时间控制

访问分析（实时日志、地图和多维数据分析）

用于创建链接的 API 集成

### 电子邮件服务：
创建自定义前缀电子邮件

过滤未读电子邮件列表

无限创建邮箱

接收无限制的电子邮件（由 Cloudflare Email Worker 提供支持）

发送电子邮件（由 Ressend 提供支持）

用于创建邮箱的 API 端点

用于收件箱检索的 API 端点

### 子域名管理服务：
跨多个 Cloudflare 帐户和域管理 DNS 记录

创建各种 DNS 记录类型（CNAME、A、TXT 等）

### 开放 API 模块：
网站元数据提取 API

网站截图捕获 API

网站二维码生成 API

将网站转换为 Markdown/文本格式

全面的 API 调用日志记录和统计信息

为第三方集成生成用户 API 密钥

### 管理员模块：
具有网站分析的多维仪表板

动态服务配置（切换短链接、电子邮件、子域管理）

用户管理（权限、配额、账户控制）

集中式短链接管理

集中式电子邮件管理

集中式子域管理
