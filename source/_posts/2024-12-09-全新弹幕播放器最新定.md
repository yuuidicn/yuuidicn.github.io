## 全新弹幕MizhiPlayer播放器，最新UI定制版，支持去广告
现在大部分的视频播放器都是 BILI 的，且很多外面的播放器自定义自由度太低了，对小白不太友好，

而且也好久没有更新了，因为花了一段时间重新根据 ARTPLAYER 内核以及参考了众家之所长编写了一个全新版本强大的 ART弹幕播放器系统

### 更新日志：
V24-12-1 版本 时间 2024-11-27 提前发布

1.新增专用接口设置(去插播)资源站去广告功能，填入你的接口和特征码域名即可

新增官方接口设置 JSON 接口中切片资源接口适配，非标准 URL 地址也可正常解析（2024 年 11 月 27 日）

2.新增弹幕 ID 接口加密方式功能，适配市面上的其他远程弹幕 API 接口

3.新增管理员后台弹幕预设值控制，例如：默认弹幕显示 1/4 还是其他，详情看后台设置

4.新增后台弹幕滚动速度控制

7.新增弹幕库接口地址以及弹幕接口参数配置，只要弹幕返回参数一致即可

8.新增后台弹幕字体大小控制

9.优化部分的样式错位的问题

10.优化部分按钮无效点击的问题

11.新增暂停广告右上角显示当前广告位图片地址内容

12.新增解决支持部分的 JSON 接口重定向隐藏真实地址视频地址导致不能播放的问题

13.支持 m3u8 格式的直链特征码模式，添加特征码域名即可走接口解析不走直链

14.播放器更新已更新两个大版本，欢迎各位提意见，有问题的都会一一解决

15.如您已购买本播放器请勿传播否则取消更新资格，自用即可，如泛滥我会随时停止更新，且用且珍惜

V24-11-20 版本

觅知全新定制 UI 播放器 ARTplayer 内核开发多功能弹幕播放器

播放器全代码均全本地化无任何外链和远程链接！！！（仁者见仁智者见智，我不想在解释了！）

2024 全新定制管理员后台管理播放器程序

新增管理后台登入大小写提示

众多管理员后台功能，修改密码，登入退出等功能

新增暂停视频，悬浮罩层介绍内容

新增视频加载动态内容样式

新增视频调色板，饱和度，对比度，明亮度调节

新增播放器进度条缩略图预览

支持苹果 CMS 下一集播放

新增跑马灯功能，可在后台自行设置内容和参数

解析失败自定义显示内容功能

JSON 接口后台配置功能，目前只加了 5 条接口，一般来讲都够用了吧

解析接口轮训，第一条接口开始解析，直到解析成功，每个接口的最大解析时间为 5 秒

播放器支持直链播放，不经过接口，支持 MP4.MU38.FLV.等等（部分直链需要跨域）

解析接口 JSON 防止被盗用

新增专用接口设置(去插播)资源站去广告功能，填入你的接口和特征码域名即可

基本上播放器所见功能管理后台均可以管理，高自定义
