## ChatGPT小程序美化版 ,超快回复速度
1.拉取项目后执行命令 npm install

2.使用Hb工具打开项目 并中找到util包下的env.js修改相应配置

3.点击根目录下的 manifest.json 找到要部署平台的appid 修改为自己的appid

4.HB导航栏选择运行到XXX模拟器(具体看你部署平台)

5.拉取后端项目 找到application.yml 可根据自己需求调整相应配置 基本都写了注释 看着改就行

6.无误后maven打包上传jar 开始跑……..

7.newBing 工件需要额外 node环境部署 请确保你的服务器有node且版本大于 18 拉下来 找到两个 env文件 把其中的cookie换成你的newBing cookie npm install

### 更新日志：
支持Ai回复 code渲染 code块长按复制

支持ai回复 图片保存 以及单击预览

输入console可以打开控制台查看后台状态以及配置key池

支持历史数据保存(仅对话可用不会保存图片聊天数据)

### 系统模式
数据流控制( 对ai回复内容使用流传输 WebSocket, 关闭则等全部数据获取完毕后回显)

长按悬浮球 可打开key捐献渠道

支持ai当前对话 (如 用户:你好 ai:你也好 用户:我刚刚说了什么? ai:你刚刚说了你好)

引入动画控制 (捐献key时会触发烟花特效 碎布数量为500 抛射角度为60 低端机型可能稍微卡顿,可调整,该设置关闭将会 将切换过场动画 以及 输入框渐入 等特效关闭)

单击悬浮球切换 (gpt对话 gpt绘图 newbing对话 轮换操作)

单击输入框最左打开设置 最右(垃圾箱)表示清理当前页面数据

ai回复中断(未实装)

newBing不受缓存池影响

新增一些lottie动画
