# Hexo后台管理系统，独家发布

这是一个基于PHP的Hexo后台管理系统，对接GitHub上的Hexo博客集成，提供可视化的文章管理和发布功能。

文章管理

✓ 查看所有文章列表

✓ 新建文章

✓ 编辑现有文章

✓ 删除文章

✓ 自动同步到 GitHub

图片管理

✓ 单张图片上传

✓ 批量图片上传

✓ 图片库展示

✓ 复制图片链接

✓ 删除图片

✓ 自动同步到 GitHub

GitHub 集成

✓ GitHub API 对接

✓ 自动同步文章

✓ 自动同步图片

✓ 连接状态检测

✓ Commit 记录

控制台

✓ 文章数量统计

✓ 图片数量统计

✓ GitHub 连接状态

✓ 最近文章列表

✓ 快速操作入口
